# cowork-flow documentation

[中文](index.md) | English

If this is your first time installing and using cowork-flow, read [README](../README.en.md) first. When you need to understand host integration, how it works, or the development workflow, pick a document from the entries below.

## Find by question

| What you want to do | Which document to read | What you will find |
|---|---|---|
| Install, initialize a project, or start a task | [README](../README.en.md) | The shortest path to get started, day-to-day commands, and common questions |
| Connect cowork-flow to an AI coding host | [Host integration](hosts.en.md) | Installation components, restart requirements, upgrades, uninstallation, and troubleshooting for each host |
| Understand how project files are organized | [Architecture and extension](architecture.en.md) | The runtime, `template/`, `presets/`, sync policy, and extension boundaries |
| Contribute to project development | [Contributing](../CONTRIBUTING.md) (Chinese) | Local setup, code conventions, tests, and PR checks |
| Understand the test and release process | [Release and maintenance](release.en.md) | Test layers, CI, version releases, and maintainer commands |
| Understand project direction and version planning | [Direction](direction.en.md) | The positioning statement, settled trade-offs, the version mainline, and open items |
| See what changed in a given version | [Changelog](../CHANGELOG.md) (Chinese) | Feature changes, fixes, and migration notes recorded by version |

## Common reading paths

- **First-time use**: README → Host integration → Start a task.
- **Submitting code**: README → Contributing → Architecture and extension.
- **Troubleshooting installation or runtime issues**: Host integration → the "Troubleshooting" section of README.
- **Preparing a release**: Architecture and extension → Release and maintenance → Changelog.

## Documentation and actual behavior

Documentation explains usage; for exact commands and current task state, rely on what the command actually outputs. For the command that shows the current state, see the "Troubleshooting" section of [README](../README.en.md).

If command output disagrees with the documentation, trust the current command output and open an [issue](https://github.com/fishlikewater/cowork-flow/issues) to point out where the documentation needs fixing.
