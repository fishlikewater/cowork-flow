# cowork-flow 文档

第一次安装和使用请先看 [README](../README.md)。需要了解宿主接入、工作原理或开发流程时，再从下面的入口选择文档。

## 按问题查找

| 你想做什么 | 看哪份文档 | 能找到什么 |
|---|---|---|
| 安装、初始化项目或开始一个任务 | [README](../README.md) | 最短使用路径、日常命令和常见问题 |
| 把 cowork-flow 接到某个 AI 编码宿主 | [宿主接入](hosts.md) | 各宿主的安装组件、重启要求、升级、卸载和排障方式 |
| 了解项目文件如何组织 | [架构与扩展](architecture.md) | 运行时、`template/`、`presets/`、同步策略和扩展边界 |
| 参与项目开发 | [参与开发](../CONTRIBUTING.md) | 本地环境、代码约定、测试和 PR 检查 |
| 了解测试与发布流程 | [发布与维护](release.md) | 测试分层、CI、版本发布和维护者命令 |
| 了解项目方向与版本规划 | [方向规划](direction.md) | 定位声明、已拍板取舍、版本主线与待决项 |
| 查某个版本改了什么 | [更新日志](../CHANGELOG.md) | 按版本记录的功能变化、修复和迁移说明 |

## 常见阅读路径

- **第一次使用**：README → 宿主接入 → 开始一个任务。
- **提交代码**：README → 参与开发 → 架构与扩展。
- **排查安装或运行问题**：宿主接入 → README 的“遇到问题”。
- **准备发布**：架构与扩展 → 发布与维护 → 更新日志。

## 文档与实际行为

文档用于解释用法，具体命令和当前任务状态以运行结果为准；查看当前状态的命令见 [README](../README.md) 的“遇到问题”。

如果命令输出与文档不一致，请以当前命令输出为准，并提交 [Issue](https://github.com/fishlikewater/cowork-flow/issues) 指出文档需要修正的位置。
