# cowork-flow 文档

第一次安装和使用请先看 [README](../README.md)。需要了解宿主接入、工作原理或开发流程时，再从下面的入口选择文档。

| 你想做什么 | 看哪份文档 | 能找到什么 |

| 安装、初始化项目或开始一个任务 | [README](../README.md) | 最短使用路径、日常命令和常见问题 |
| 把 cowork-flow 接到某个 AI 编码宿主 | [宿主接入](hosts.md) | 各宿主的安装组件、重启要求、升级、卸载和排障方式 |

## 常见阅读路径

- **第一次使用**：README → 宿主接入 → 开始一个任务。
- **提交代码**：README → 贡献指南 → 工作原理与扩展点。
- **排查安装或运行问题**：宿主接入 → README 的“遇到问题”。
- **准备发布**：工作原理与扩展点 → 开发与发布 → 更新日志。

## 文档与实际行为

文档用于解释用法，具体命令和当前任务状态以运行结果为准：

- 查看命令和参数：`cwf --help` 或 `cwf <group> <command> --help`
- 查看任务下一步：`./.cowork-flow/run task next --json`
- 查看宿主支持情况：`cwf host list`
- 检查本机与项目状态：`./.cowork-flow/run doctor --all`

如果命令输出与文档不一致，请以当前命令输出为准，并提交 [Issue](https://github.com/fishlikewater/cowork-flow/issues) 指出文档需要修正的位置。
