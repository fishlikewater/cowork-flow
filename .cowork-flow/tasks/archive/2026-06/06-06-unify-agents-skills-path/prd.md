# 统一 Skill 目录为 .agents

## 目标

将项目内所有面向 Agent Skill 的旧单数目录约定统一修正为 `.agents`，与 Codex/OpenCode 的标准 Skill 发现路径保持一致。

## 范围

- 将仓库根目录和 `template/` 下的旧单数 skills 目录迁移为 `.agents/skills`。
- 修正脚本、代码、配置、文档、测试和模板中的旧单数路径引用。
- 不保留旧单数目录兼容分支、软链或 fallback。

## 非目标

- 不改变 Skill 文档自身的流程语义。
- 不引入新的 Skill 加载机制。
- 不调整与本次路径更名无关的运行时派发逻辑。

## 验收标准

- 仓库中不存在旧单数 Agent 目录。
- 除普通字段名外，工作区文件不再出现旧单数路径引用。
- `.agents/skills/**/SKILL.md` 在根目录和 `template/` 下保留原有 Skill 内容。
- 相关测试或脚本验证通过，至少覆盖全局路径扫描和项目现有测试入口。

## 验证方式

- 旧单数目录查找命令
- 旧单数路径引用扫描命令
- 项目现有测试命令或针对性测试命令
